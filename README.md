# Kitsune Linux 

This repository creates a immuatuble linux base image using bootc.

Focused on container based "security" and a read only base system with the benefits of modern kernel performance enhancement using x86-64v3 patches. 

Special thanks to the documentation by Redhat/Fedora, uBlue, bootc, & bootcrew.
